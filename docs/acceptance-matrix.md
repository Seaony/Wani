# Wani 功能与设计验收矩阵

本文档记录 Wani 的实现基线。功能证据来自 2026-08-26 对本机 Things 3 的实际界面检查及 [Things 官方 macOS 快捷键清单](https://culturedcode.com/things/support/articles/2785159/)；视觉证据来自桌面 `Wani/Todo Redesign.dc.html` 及其配套图片。

## 基线优先级

1. 界面视觉、布局和状态表现以 `Todo Redesign.dc.html` 为准。
2. 任务管理的功能和操作流程以实际检查到的 Things 3 行为为准。
3. 同步使用用户私有 iCloud/CloudKit，不复刻 Things Cloud。
4. 设计稿没有覆盖的功能沿用同一视觉语言，不复制 Things 3 的专有图像资源。

## 核心功能

| 功能单元 | 已确认的 Things 3 行为 | Wani 验收标准 |
| --- | --- | --- |
| 智能列表 | 收件箱、今天、计划、随时、某天、日志簿、废纸篓 | 分类、计数、空状态和跳转全部正确 |
| 今天 | 支持普通时段与“今晚”；可按项目或区域分组 | 今天任务与今晚任务分区正确 |
| 计划 | 按日期分组展示未来任务 | 跨月日期、空日期和任务数量正确 |
| 日志簿 | 完成和取消的项目可归档；归档时间可配置；午夜归档前完成项留在原列表，也可用 `⇧⌘Y` 立即记录；明确归档标题则立即记录 | 完成/取消状态可恢复且按日期展示；原列表、搜索定位与待办计数保持一致 |
| 废纸篓 | 删除项进入废纸篓；多选已删除待办时仍可使用时间、移动及完成/取消，删除操作禁用 | 可恢复、永久清理；批量移动会恢复并移出废纸篓，其他列表不再显示 |
| 区域 | 区域用于按责任范围组织项目和任务 | 新增、编辑、排序、折叠和删除行为正确 |
| 项目 | 项目包含目标、备注、任务和完成进度 | 新增、编辑、排序、移动、完成和进度正确 |
| 标题 | 项目页底部工具栏提供“新建标题”；点击后在任务区整行内联编辑，不常驻占位行；可从选中且尚未分组的待办创建标题；其待办全部关闭后可归档 | 标题分组、排序及任务移动正确；回车保存、Esc 取消；选中待办一并移入新标题；归档标题进入项目底部已记录项并可恢复 |
| 任务编辑 | 标题、备注、可拖放排序的检查清单、标签、时间、截止日期、提醒 | 所有字段可编辑；内联文本与检查项顺序变化立即更新时间戳并保存、搜索和同步 |
| 完成状态 | 可标记为已完成或已取消，也可撤销；Items 菜单以完成子菜单提供两种关闭动作 | 列表、计数、项目进度和日志簿同步更新；未选中待办时菜单动作禁用 |
| 时间 | 今天、今晚、指定日期、某天、清除；选中一个或多个待办后可从底部“时间”、Items 菜单或 `⌘S` 打开日期编辑；`⌘T`、`⌘E`、`⌘R`、`⌘O` 分别直接安排到今天、今晚、随时、某天，并可为选中项添加提醒 | 单项与批量设置及直接快捷键执行后，智能列表归类和日期变化正确；批量提醒按各任务安排日期使用同一时间；未选中待办时工具栏与菜单操作禁用 |
| 截止日期 | 可从 Items 菜单或 `⇧⌘D` 为一个或多个待办打开截止日期编辑 | 批量设置或清除后每个选中项一致更新，提醒通知随日期变化重新同步；未选中待办时菜单项禁用 |
| 重复 | Items 菜单或 `⇧⌘R` 打开独立规则面板；支持定期或完成后、每天、每周、每月、每年、间隔、每周多个执行日、月/年多条日期规则、结束条件、提醒和截止日期；定期规则即时预览下一组日期；新建规则默认完成后每 1 周 | Save 后规则与日期元数据持久化并在触发条件满足时生成下一项；定期规则按所选星期或月年日期与间隔生成并即时预览，缺失日期不漂移，结束条件生效；Cancel 或 `Esc` 关闭且不写入；多选时规则编辑禁用 |
| 移动 | 任务可从底部“移动”、Items 菜单或 `⇧⌘M` 移到其他项目、标题或脱离项目 | 目标列表、排序和项目计数即时更新；未选中待办时工具栏与菜单操作禁用 |
| 标签 | 任务可设置标签，项目页可按标签筛选；Items 菜单可打开标签编辑，多选时标签面板以未选、混合、全选三态统一增删 | 单项与批量标签增删、搜索、筛选和同步正确；未选中待办时菜单操作禁用 |
| 搜索 | 快速查找覆盖任务和列表，并显示任务所属位置 | 覆盖标题、备注、标签、项目和区域，结果可定位 |
| 快速录入 | 应用内快捷录入；Things 3 还提供全局快捷键窗口 | 应用内 `N` 与可配置全局快捷键可保存到指定列表 |
| 键盘导航 | `↑`、`↓` 移动单项选择；`⇧↑`、`⇧↓` 扩展连续选区；`⌥↑`、`⌥↓` 跳到首尾；`⌥⇧↑`、`⌥⇧↓` 扩展到首尾；Return 打开单个选中项 | 所有快捷键按当前屏幕顺序工作；多选后普通方向键越过选区并收拢为单选；文本输入和弹层不被列表导航抢键 |
| 多选与编辑 | 全选、拷贝文本、复制任务、从剪贴板逐行新建任务、批量设置时间、提醒、截止日期、标签、移动和删除 | `⌘C` 拷贝所选任务标题；`⌘D` 创建保留内容与状态、具有独立标识且紧邻原项的副本，并只选中新副本；列表中 `⌘V` 为剪贴板每个非空行创建一项并选中新项，文本输入框仍执行普通粘贴；其他多选操作对每个选中项一致生效；窄窗口自动使用仅图标工具栏，不出现文字折行或裁切 |

## 数据与同步

- 区域、项目、标题、任务和检查项使用稳定 UUID。
- 排序值、软删除时间、完成/取消时间和重复规则必须进入持久化模型。
- 任务、层级关系、标签、日期、提醒和排序均进入用户私有 CloudKit 数据库。
- 本地数据库是离线工作副本；CloudKit 不可达时不阻塞增删改。
- 模型与同步容器不得依赖 AppKit 视图，以便未来 iOS target 直接复用。
- 签名与双实例同步的实测状态见 [iCloud 验收记录](icloud-validation.md)。

- 单元测试覆盖智能列表归类、日期边界、计数、完成/删除恢复、搜索和重复规则。

- 每个功能单元先通过 `xcodebuild`，再使用 Computer Use 在 Wani 中执行真实流程。
- 浅色、深色、窄窗口和宽窗口均需与设计稿比较。
- 当前后台构建和测试状态见 [后台构建与测试记录](build-validation.md)。
- 当前人工检查状态见 [界面验收记录](ui-validation.md)。
