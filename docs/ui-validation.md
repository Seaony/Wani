# Wani 界面验收记录

## 2026-08-26：人工检查

本次检查使用 Debug 构建和现有本地数据，未运行 UI 自动化。

已检查通过：

- 标准窗口下的浅色双栏布局、侧栏导航、页面标题、空状态与底部工具栏。
- 侧栏显示与隐藏，当前列表和内容区状态保持不变。
- Appearance 设置页的浅色、深色、强调色、侧栏选项与密度控件布局；检查后已恢复浅色主题。
- Quick Entry 设置页的应用内快捷键、全局快捷键和默认保存位置布局。
- Sync 设置页能明确显示 Debug 启动正在使用本地存储，没有把本地模式显示成已连接 CloudKit。
- 快速录入面板的标题输入、保存目标、保存和退出提示布局。
- 全局搜索面板的输入框、快捷键提示和空查询状态布局。
- 项目页的项目名称、备注和 Heading 均使用页面内直接编辑，没有弹出命名对话框。
- 窄窗口和宽窗口下的双栏、项目页与区域页布局；窄窗口发现的 29 pt 内联名称裁切已修复并复验，宽窗口没有出现异常拉伸。
- 有内容时的任务行和展开编辑卡片；标题、备注、检查项、标签、日期与任务操作均存在于可访问性树，卡片边界和工具栏在窄窗口保持完整。
- 多选和拖放：`⌘A` 会选中当前列表全部任务并显示批量工具栏；废纸篓中再次 Trash 已禁用，批量移动到 Inbox 会恢复任务；任务拖动重排后切换列表再返回，顺序保持不变。
- 批量时间：多选后底部工具栏显示 When，`⌘S` 可打开暖色日期面板；Today、Evening、Tomorrow、Anytime、Someday、指定日期均有独立可访问标签，实测三条 Inbox 任务可一次移入 Someday。
- 批量提醒与截止日期：Items 菜单在未选择任务时禁用 When 和 Deadline，选择两项后启用；When 面板的 Add Reminder 可展开时间输入，实测两条 Inbox 任务使用相同时间建立提醒并安排到 Today，任务行均显示铃铛。Deadline 打开独立暖色日期面板，批量应用后两条任务均显示旗标；随后已逐项清除提醒和截止日期，并将临时任务移入废纸篓。
- Items 菜单：实机复核 Things 3 的时间、移动、标签、截止日期及完成子菜单结构后，Wani 使用相同分组接入现有任务动作。无选择时编辑项与完成动作不可用；实测单项任务可从菜单进入 Tags 暖色面板，两项选择时可打开同一面板和 Move 遮罩，并可从 Completion 子菜单批量取消；临时任务随后均已恢复并移入废纸篓。
- 重复规则：实机确认 Things 3 使用独立 Repeat 面板，新建默认完成后每 1 周；定期每周规则可添加多个星期几，每月规则使用序号与日/星期组合，每年规则再增加月份，月年规则均可添加多条；结束条件提供从不、若干次后和指定日期，并即时显示下一组执行日期。Wani 的暖色面板实测默认值一致，可切换 Regularly/After Completion 和日、周、月、年间隔；Regularly + Weekly 下可选择多个星期几，Month/Year 下可增删多条日期规则，结束条件可选择 Never、After 或 On Date。实测 Next 预览会随周/月规则即时更新，次数上限设为 1 时仅显示首个日期且不显示省略号；两条月度规则保存后重新打开仍保持，Year 模式会为每行显示月份；星期规则、结束日期和次数上限也均可重开保持。临时任务随后均已移入废纸篓。
- 批量标签：多选后 Tags 打开暖色标签面板，未选、混合、全选三态均能通过辅助功能读取；实测标签可同时应用到两条 Inbox 任务，全局搜索返回 2 项，Clear 后从全部选中项移除。宽窗口显示图标与文字，窄窗口自动切换为仅图标工具栏，不再逐字换行。
