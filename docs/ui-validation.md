## 2026-08-27：iOS 小组件

使用 iPhone 17 Pro（iOS 26.5）模拟器和 Debug 内存存储，对照 `iOS App.dc.html` 的 Widgets 区域完成系统小组件图库与实际桌面、锁屏验收；没有运行 UI 自动化。

已使用 Computer Use 检查通过：

- 系统主屏小组件图库识别 Wani 的 Today at a Glance 小号、Today List 中号、Next Up 小号和 Upcoming 大号，四种系统预览的尺寸、暖色卡片、排版与样例内容均与设计稿对应。
- Next Up 已实际加入主屏并读取主应用通过 App Group 导出的快照；点击 `1d` 后任务的开始日期与截止日期同时顺延，Today 从 5 降到 4，Widget 切换到下一项。

- 主屏与锁屏小组件均跟随系统提供的浅深色容器环境；Widget 每 15 分钟请求新时间线，主应用写入新快照后主动请求全部时间线刷新。

- 有内容时的任务行和展开编辑卡片；标题、备注、检查项、标签、日期与任务操作均存在于可访问性树，卡片边界和工具栏在窄窗口保持完整。
- 多选和拖放：`⌘A` 会选中当前列表全部任务并显示批量工具栏；废纸篓中再次 Trash 已禁用，批量移动到 Inbox 会恢复任务；任务拖动重排后切换列表再返回，顺序保持不变。
- 任务复制：实机确认 Things 3 的 Edit 菜单将拷贝文本与复制待办事项分开，复制快捷键为 `⌘D`；Wani 保留 `⌘C` 拷贝标题，并在 Edit 菜单与批量工具栏提供 Duplicate。实测单项与两项批量复制均紧邻原项插入，只选中新副本，备注与检查清单保持不变；临时任务随后均已移入废纸篓。
- 剪贴板新建：按 Things 官方 macOS 快捷键行为，Wani 的 Edit 菜单保留标准 Cut、Copy、Paste；列表中粘贴两行实测创建两条 Today 待办并同时选中新项，标题字段获得输入焦点后粘贴只修改文本且任务总数不增加。临时任务随后均已移入废纸篓，验收工具已恢复原剪贴板。
- 键盘导航：实机确认 Things 3 的普通方向键会移动单选，多选后会越过当前选区并收拢为单选，Shift 方向键扩展连续选区；Wani 实测 `↑`、`↓` 单选，`⇧↑`、`⇧↓` 连选，`⌥↑`、`⌥↓` 跳到首尾，`⌥⇧↑`、`⌥⇧↓` 扩展到首尾，Return 展开单个选中任务。任务标题输入框聚焦时方向键保持文本编辑行为，临时任务随后均已移入废纸篓。
- 键盘排序：按 Things 官方快捷键清单补齐 `⌘↑`、`⌘↓` 逐项移动和 `⌥⌘↑`、`⌥⌘↓` 移到当前列表首尾。Wani 实测单选任务和展开任务均能保持选中或展开状态完成排序，移动限制在当前项目、标题、区域或智能列表分组内；临时任务随后均已移入废纸篓。
- 编辑快捷键：按 Things 官方快捷键清单补齐 `⌘Return` 保存并关闭展开任务、`⌘K` 完成、`⌥⌘K` 取消，并将侧栏、搜索层和设置中的 Search 提示统一为 `⌘F`。实测 `⌘K` 不再误开搜索，完成与取消任务正确离开 Anytime 并进入 Logbook；任务行的展开状态随列表切换销毁，不会在 Logbook 同时残留多张编辑卡片。`⌘F` 可打开搜索且第一次按 `Esc` 即关闭；临时任务随后均已移入废纸篓。
- 检查清单快捷键：实机确认 Things 3 在展开待办中按 `⇧⌘C` 会新建空检查项并把焦点移入其文本框。Wani 实测同一快捷键聚焦现有的“Add checklist item”输入行，输入并回车后检查项立即保存，焦点继续停留在下一条空输入行；临时任务随后已移入废纸篓。
- 所选任务下方新建：按 Things 官方快捷键清单补齐 Space。实测在 Anytime 选中四项中的第二项后按 Space，Quick Entry 显示正确目标，保存后的新任务紧邻所选项插入并成为唯一选中项；任务标题输入框聚焦时 Space 保持普通文本输入，不会误开录入层。临时任务随后均已移入废纸篓。
- 批量时间：多选后底部工具栏显示 When，`⌘S` 可打开暖色日期面板；Today、Evening、Tomorrow、Anytime、Someday、指定日期均有独立可访问标签，实测三条 Inbox 任务可一次移入 Someday。
- 日期快捷键：按 Things 官方 macOS 快捷键清单补齐 `⌘T` 今天、`⌘E` 今晚、`⌘R` 随时、`⌘O` 某天、`⇧⌘D` 截止日期和 `⇧⌘R` 重复规则。实测批量选择后 `⌘O` 直接移入 Someday，展开单项后 `⌘T` 直接移入 Today；`⇧⌘D` 打开含 Deadline 控件的日期面板，`⇧⌘R` 打开 Repeat 面板。临时任务随后已移入废纸篓。
- 日期微调快捷键：按 Things 官方 macOS 快捷键清单补齐开始日期的 `⌃]`、`⌃[`、`⌃⇧]`、`⌃⇧[` 和截止日期的 `⌃.`、`⌃,`、`⌃⇧.`、`⌃⇧,`。实机确认 Things 在无开始日期时向前一天会安排到明天、向后一天会落在今天；Wani 实测 Today 所选任务按 `⌃]` 后进入 Upcoming 的明天分组，离开当前列表后不会残留底部选择状态。日周偏移、今天下限及提醒时刻保持由 50 项后台单元测试覆盖；临时任务随后已移入废纸篓。
- 批量提醒与截止日期：Items 菜单在未选择任务时禁用 When 和 Deadline，选择两项后启用；When 面板的 Add Reminder 可展开时间输入，实测两条 Inbox 任务使用相同时间建立提醒并安排到 Today，任务行均显示铃铛。Deadline 打开独立暖色日期面板，批量应用后两条任务均显示旗标；随后已逐项清除提醒和截止日期，并将临时任务移入废纸篓。
- Items 菜单：实机复核 Things 3 的时间、移动、标签、截止日期及完成子菜单结构后，Wani 使用相同分组接入现有任务动作。无选择时编辑项与完成动作不可用；实测单项任务可从菜单进入 Tags 暖色面板，两项选择时可打开同一面板和 Move 遮罩，并可从 Completion 子菜单批量取消；临时任务随后均已恢复并移入废纸篓。
- 重复规则：实机确认 Things 3 使用独立 Repeat 面板，新建默认完成后每 1 周；定期每周规则可添加多个星期几，每月规则使用序号与日/星期组合，每年规则再增加月份，月年规则均可添加多条；结束条件提供从不、若干次后和指定日期，并即时显示下一组执行日期。Wani 的暖色面板实测默认值一致，可切换 Regularly/After Completion 和日、周、月、年间隔；Regularly + Weekly 下可选择多个星期几，Month/Year 下可增删多条日期规则，结束条件可选择 Never、After 或 On Date。实测 Next 预览会随周/月规则即时更新，次数上限设为 1 时仅显示首个日期且不显示省略号；两条月度规则保存后重新打开仍保持，Year 模式会为每行显示月份；星期规则、结束日期和次数上限也均可重开保持，`Esc` 可直接取消并关闭面板而不保存。临时任务随后均已移入废纸篓。
- 批量标签：多选后 Tags 打开暖色标签面板，未选、混合、全选三态均能通过辅助功能读取；实测标签可同时应用到两条 Inbox 任务，全局搜索返回 2 项，Clear 后从全部选中项移除。宽窗口显示图标与文字，窄窗口自动切换为仅图标工具栏，不再逐字换行。
